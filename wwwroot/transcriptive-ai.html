THE OVERVIEW

Turning medical language into structured information.

Medical transcription brings together complex language, structured records, and the people who use them. This team project explores that workflow through Android and desktop interfaces, backed by data services and an NLP system.

INSIDE THE PROJECT

What I worked on.

01

An Android application

Built a Kotlin app with user registration, authentication, and hospital staff management. Integrated Firebase for backend services and persistent user and staff data.

02

A desktop workflow

Developed the original VB.NET interface for transcription input, structured note generation, transcription history, and settings.

03

Language processing

Contributed to a Python/PyTorch NLP system for medical specialty classification, entity extraction, and transcription error detection using the MTSamples dataset.

04

Iterative teamwork

Worked in an Agile team, contributing to feature planning, testing, project reviews, and iterative development.
