THE OVERVIEW

A programming language closer to everyday English.

SimpleEnglish explores how familiar language can express programming concepts. The project centers on a custom context-free grammar and the lexical and parsing rules that make its structure consistent.

INSIDE THE PROJECT

What I worked on.

01

Core language constructs

Designed an English-like grammar supporting variables, typed expressions, control flow, functions, and input/output constructs.

02

Expression rules

Defined arithmetic, comparison, and logical expressions with explicit operator precedence.

03

Nested structure

Handled nested statements and block structure through ANTLR parsing rules.
